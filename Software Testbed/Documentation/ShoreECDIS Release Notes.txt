ShoreECDIS Release Notes

2.1.0.0

*** CURRENT LIMITATIONS:

 - You must remove the %LOCALAPPDATA%\NIWC\ShoreECDIS\ShoreECDIS.user.configdb before using an older version

 - S-57 ENC Charts do not provide route validation alerts for monitoring or planning modes

* Enhancements

 - New application color scheme

 - S-57 Support

 - Temporal input
   - Time slider and calander range inputs
   - Current and Custom time selection modes. Current mode will make chart re-render calls every minute
   - Double-click temporal limited dataset in chart library will update custom time selection of chart when centering on chart

 - Mouse Drag compositor area, with overscale area dragged into view on intermediate rendering

 - Mouse wheel zoom progressive based on mouse wheel speed (not simply switching between pre-defined zoom levels)

 - Skin of Earth base render layer

 - Projection support
  - Mercator (existing 1SP type)
  - Web Mercator
  - World Mercator
  - Cylindrical Equidistant
  - Lambert Conformal (North/South)
  - Polar Stereographic (North/South)

 - GPS Configuration
  - Serial - COM on windows supports USB and traditional serial connections
  - TCP - Client dials out (This matches the IEC 61162-450 / standard maritime integration paradigm where the gateway is the producer and multiple clients, such as ShoreECDIS can subscribe by connecting in)
  - UDP - Datagrams in UDP packets on the configured port will be split by \r\n into multiple NMEA messages

 - SENC Migration support. Old versions of the program are usable with previously installed data.

 - Display Mode and Independent Viewing Group persistence. All Display Modes are static, and if any of the Standard/Other Information viewing group layers or groups are removed, the portrayal settings will show user in "Custom" mode. Custom modes aren't persisted after shutdown, and restarting the program will put individual products in their previous display modes with any of the persisted independent viewing groups but none of the custom changes.

 - Allow change of individual product's color palettes from the global selected color profile (If a portrayal catalog is missing a color palette will show as "Missing" but can be changed to begin displaying the product again)

 - Include decryption capabilites for:
  - S-100 Documentation MasterKey/Manufacturer id
  - Public S-63 key used for sea trials testing
  - S-64 Encrypted datasets keys
  - Hardware locked encryption forced, so UserPermit issued during registration must be found in PERMIT.TXT or PERMIT.XML dataset keys

 * Fixes

  - Load portrayal_catalogue.xml verbatim. Won't cause error if another portrayal_catalogue.xml is found in the same folder structure

  - Doesn't freeze chart while installing data sets

  - Load fonts from portrayal catalogs

  - Drag CATALOG.XML (or CATALOG.031) onto Chart or Chart Library to install exchange sets

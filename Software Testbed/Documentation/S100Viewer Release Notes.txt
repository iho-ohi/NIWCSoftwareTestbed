    - S-64 Encrypted datasets keys

1.4.0.0
  Notes:
    This release is intended to support manufacturer evaluation of the Lua S-101 portrayal, especially in terms of performance.
	  - Both XSLT and Lua portrayal catalogues are supplied - be sure to use the appropriate catalogue when evaluating performance.
      - Use the "Show Logs" button (up arrow) next to the "Error(s)" indicator to show the logs, then select "Performance". This will show a detailed timing analysis of each step in the Lua portrayal. Note that the "Render" times should be ignored as they are not part of the portrayal.
	  - Performance considerations:
	    * The drawing instructions for Lua portrayal scripts are cached in a SQLite database file.  To disable or enable this feature, select "Portrayal/Cache Enabled" from the main menu bar.
		* The drawing cache can be cleared by selecting "Portrayal/Clear Cache" from the main menu bar.
		* The initial portrayal generation after loading a dataset the first time should be interpreted as the amount of time the hosts dataset installer would use to pre-generate a portrayal.  This time can also be determined by clearing or disabling the cache.
		* The performance tab reports the elapsed times for different parts of the portrayal process as follows:
		  o Portrayal Total   -- This reports the overall time spent generating the drawing instructions for the current dataset.  These times don't include rendering the drawing instructions.  This value is the addition of the following two times.
		  o Lua Code - Total  -- This reports the overall time spent executing Lua code.
		  o Host Code - Total -- This reports the overall time spent executing Host code (i.e. the S-100 Viewer program itself).
		* The effort in this release has been directed at optimizing the Lua code.  The host code is strictly written with correctness and simplicity in mind and the performance timings should not be taken as indicative of the time needed in a production application.
		* Changes to context parameters should be used to evaluate the amount of time needed to re-generate cached drawing instructions.
  Changes:
    Reworked Lua portrayal to follow changes in "S-100 Scripting" and "S-100 Lua Portrayal" proposed standards.
      Note: These changes are still in a state of flux and will result in minor Lua script file changes in future versions of S-100 Viewer.
    Lua portrayal now uses a command based model for drawing instructions vs. the descriptive model used in the previous version.
      - The command based model follows the concepts in the descriptive model used by XSLT portrayal.
      - The command based model is easier for the host to parse and execute.
	  - The command based model makes it easier to implement and test scripts.
    Replaced the Lua 5.3 interpreter with LuaJIT for increased performance.
      - Lua scripts are now based on the Lua 5.1 standard instead of the 5.3 standard.

1.3.0.0
  Rewrite to support generic browsing of S-100 products, not just S-101
  Added some dataset validation during dataset loading (incomplete)
	- ISO-8211 encoding: reports when encoding deviates from S-100 (e.g. point reference missing from curve record)
	- Feature Catalogue validation: checks for missing required elements (e.g. a required attribute is not present on a feature)
	- Validation results are shown during loading, and are also available in the diagnostic tab after the dataset has loaded
  Added support for Lua portrayal rule files (when prompted for a portrayal catalogue during dataset loading, select one that contains Lua rule files)
  User Interface:
    Refactored to mimic modern web browser UI
    Multiple datasets and feature catalogues can now be loaded, each will display in a separate tab
		- Note: Multiple views of the same dataset can be opened, for instance to allow comparison of two portrayal catalogues
	Added calibration function to assist in accurate review of portrayal symbology
	Added ability to show multiple views:
		- ISO 8211 Dataset Browser (load dataset, select cancel when prompted for a feature catalogue)
		- ISO 8211 / S-100 Dataset Browser (load dataset, select cancel when prompted for a portrayal catalogue)
		- ISO 8211 / S-100 Dataset Browser with Portrayal
		- Feature Catalogue Browser
	Portrayal tab now supports all portrayal elements (Viewing groups, etc)
	Dataset browsers are now provided for encoded data (ISO-8211 Browser) and GFM data (S-100 Browser)
	An ISO-8211 dump view will be displayed if an attempt is made to load an invalid ISO-8211 encoded dataset
  Misc:
    Improved logging
